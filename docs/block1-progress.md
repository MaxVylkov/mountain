## Техническая карта

### Маппинг регионов (camp → mountain)
Альплагеря используют макро-регионы ("Центральный Кавказ"), горы — детальные ("Ущелье Адырсу, Кабардино-Балкария"). Функция `matchCampToMountainRegion()` в `trip-wizard.tsx` связывает их через ключевые слова из `sub_region` лагеря.

### Ключевые таблицы
- `trips` — поездки пользователя (region, mountain_id, camp_id, template, status)
- `alpine_camps` — каталог лагерей (10 записей)
- `mountains` — горы с маршрутами
- `teams` — отделения
- `team_invites` — приглашения в отделение
- `packing_sets` — снаряжение для поездки

### Будущее: фильтрация маршрутов по лагерю
На странице маршрутов: фильтр по региону → сузить до альплагеря → показать ближайшие вершины/маршруты. Связка через поле region.
