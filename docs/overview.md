# Mountaine — Обзор приложения v1.0

## Что это такое

**Mountaine** — цифровой помощник альпиниста и горного туриста. Всё что нужно для подготовки и организации похода — в одном месте: от изучения техники до координации отделения в экспедиции.

Приложение создано альпинистом для альпинистов. Ориентировано на русскоязычное сообщество — начинающих и опытных участников горных походов и восхождений.

---

## Цели первой версии

1. **Снизить порог входа** — новичок открывает приложение и видит структурированный путь: учись, собирай снаряжение, планируй маршрут, выходи в горы
2. **Стать инструментом подготовки** — опытный участник использует его для сборки снаряжения, планирования питания, координации отделения
3. **Сохранять историю** — маршруты пройдены, снаряжение учтено, прогресс в обучении виден
4. **Объединить сообщество** — делиться маршрутами, опытом, сборками снаряжения (форум — в разработке)

## Разделы приложения

### 1. База маршрутов
Каталог горных маршрутов с описаниями, сложностью (1–5), сезонностью и рекомендуемым снаряжением. Пользователь может отмечать маршруты как «пройден», «хочу пройти», «избранное». Под каждым маршрутом — комментарии сообщества с хештегами и оценками гуру.

### 2. Кладовка
Личный инвентарь снаряжения с каталогом предметов, состоянием, брендом, тегами и весом. Внутри — **сборки**: пользователь создаёт именованные наборы для конкретных походов, распределяет предметы по рюкзакам, отмечает что уже уложено.

### 3. Отделения
Групповой инструмент координации команды в многодневном походе:
- **Участники** — список с инвайт-ссылкой, роли
- **Снаряжение** — матрица кто что берёт (личное + общественное), нормы на человека и на группу, дефицит
- **Раскладка** — питание по дням, шаблоны, список покупок
- **Готовность** — чеклист для руководителя: кто что сдал/проверил

### 4. Граф знаний
Учебная программа альпинистской школы в виде интерактивного графа. Разделы: история, метеорология, навигация, безопасность, медицина, снаряжение, техника, психология. Прогресс изучения, избранное, личные заметки к узлам.

### 5. Узлы
Каталог альпинистских узлов с иллюстрациями и описаниями. Пользователь отмечает изученные узлы и отслеживает прогресс.

### 6. Тренировки
Журнал физической подготовки: упражнения, подходы, веса, даты. Простой лог тренировочного процесса.

### 7. Раскладка
Расчёт питания для похода: шаблоны раскладок (лёгкий треккинг, НП, СП-3 и др.), рецепты, список покупок с граммовкой на человека в день.

## В разработке

- **Форум** — обсуждения маршрутов, снаряжения, обучения. Умные вставки: поделиться сборкой снаряжения с кнопкой «скопировать к себе», прикрепить маршрут из базы
- **Лента** — социальная лента активности
- **Интеграция с соцсетями** — TG, Instagram, VK
